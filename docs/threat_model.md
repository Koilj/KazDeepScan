# Границы угроз и обещаний KazDeepScan

## Что оценивается

Сервис ищет акустические признаки TTS, voice conversion, клонирования голоса и частично
replay-записей. Целевые языки — русский, казахский и их смешанная речь.

## Чего результат не означает

- Он не устанавливает личность говорящего.
- Он не доказывает факт мошенничества и не оценивает содержание разговора.
- Он не гарантирует обнаружение неизвестного будущего генератора.
- Он не должен использоваться как единственное основание для блокировки пользователя.

## Безопасная реакция продукта

Результат модели всегда будет оценкой риска с тремя состояниями: `low`, `uncertain`,
`high`. Записи с недостаточной речью, сильным клиппингом, чрезмерно низким уровнем или
ошибкой декодирования не получают риск-оценку.

## Обработка данных

Голосовые записи являются чувствительными данными. Загруженный файл проходит через
временную директорию и после обработки удаляется. Сырые аудио, транскрипты, токены API и
согласия не попадают в application logs или Git. Использование записи для обучения требует
отдельного согласия и записи в реестре прав.
